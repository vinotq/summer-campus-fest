# Сириус.Капча

Станция активности для КампусФеста: игрок проходит серию интерактивных капч за ограниченное время и набирает очки в зависимости от скорости и точности ответов. Параллельно работает публичный дашборд топ-10 и админ-панель для управления вопросами и игроками.

## Печатные материалы
| Файл | Назначение | Формат |
|------|-----------|--------|
| [print/badge.html](print/badge.html) | Генератор бейджей организаторов: ввод имени, роли и станции, предпросмотр, очередь печати | 100×150 мм |
| [print/station.html](print/station.html) | Табличка станции с названием активности и номером локации | A4 альбомная, 277×190 мм |

Оба файла используют фирменные цвета и шрифт Onest. Перед печатью в браузере включить «Печать фоновой графики».

## Стек

| Слой | Технологии |
|------|-----------|
| Backend | Node.js 20+, Fastify, Socket.IO, better-sqlite3, sharp |
| Frontend | React 19 + Vite, Zustand, react-router-dom, socket.io-client |
| БД | SQLite (WAL-режим, один файл) |
| Деплой | Docker Compose: `app` (Node) + `web` (Nginx) |

## Типы капч

1. **grid3x3** — выбрать правильные фото из сетки 3×3
2. **tiles** — отметить нужные клетки поверх одного изображения
3. **slider** — переместить объект в нужную точку на фоне
4. **audio** — расшифровать аудиозапись текстом
5. **imageCode** — ввести код с искажённого изображения

## Быстрый старт (разработка)

```bash
# Backend
cd server && npm install && npm run dev

# Frontend (в другом терминале)
cd web && npm install && npm run dev
```

Сервер: `http://localhost:3000`, фронт: `http://localhost:5173`.

## Деплой

Скопировать `.env.example` в `.env`, задать пароль администратора:

```bash
cp .env.example .env

# Сгенерировать хэш пароля
docker compose run --rm app node /app/server/scripts/hash-password.js 'мой_пароль'
# Вставить результат в .env как ADMIN_PASSWORD_HASH
```

Запустить:

```bash
docker compose up -d --build
```

Nginx слушает порт `80`. Статика фронта и `/uploads/` отдаются напрямую, `/api/*` и `/socket.io/*` проксируются на `app:3000`.

## Переменные окружения

Все переменные описаны в [.env.example](.env.example). Обязательные к замене перед деплоем:

- `ADMIN_LOGIN` / `ADMIN_PASSWORD_HASH` — учётные данные администратора
- `COOKIE_SECRET` — случайная строка 32+ символов для подписи cookie
