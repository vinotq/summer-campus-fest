# 09. Экраны фронтенда (кратко)

Детали верстки и компонентов — за фронт-командой. Здесь описаны роуты, назначение и связь с API/realtime. Все контракты эндпоинтов — в `04-rest-api.md`, событий — в `05-realtime.md`, payload капч — в `03-question-types.md`.

## Стек фронта (рекомендация)
React + Vite (JS), TailwindCSS, Zustand, react-router-dom, socket.io-client. Шрифт **Onest**, цвета: фиолетовый `#814387`, оранжевый `#E77B2E`, тёмно-серый `#414141`. Логотипы — `brand/`.

---

## Игровая часть

### `/` — стартовый экран
**Назначение:** ввод Фамилии и Имени, кнопка «Начать».
**Логика:**
- Перед рендером проверяет `localStorage.cf_played`. Если есть → редирект на `/result`.
- Сабмит → `POST /api/start` → сохранить `localStorage.cf_played = '1'` → редирект на `/play`.
- Ошибка валидации — показать под полем.

### `/play` — прохождение
**Назначение:** последовательно показывает текущий вопрос.
**Логика:**
- На монт `GET /api/session/current`.
  - `status: in_progress` → отрисовать `question` по типу (router компонент `<QuestionRenderer type=... publicView=... />`), запустить локальный таймер от `startedAt + timeLimitMs`.
  - `status: finished` → редирект на `/result`.
- На сабмит ответа → `POST /api/session/answer { questionId, answerData }`.
- На ответ сервера:
  - показать короткое «+80 очков / 0» (1–1.5 с),
  - снова `GET /api/session/current` → следующий вопрос или `/result`.
- Прогресс-бар сверху по `progress.index / progress.total`.
- Таймер визуально (но решение по очкам — на сервере).
- На истечение таймера: автоотправка пустого `answerData` (некорректный → 0 очков).

### `/result` — итог + «сертификат»
**Назначение:** показать `totalScore`, разбивку по вопросам, ранг, кнопку «Скачать сертификат».
**Логика:**
- `GET /api/session/result`.
- Рендер «сертификата» в `<canvas>` с фирменными цветами и Onest, кнопка скачивания → PNG.
- Кнопка «Назад» отсутствует. Если игрок перейдёт на `/` — снова редирект на `/result` (по localStorage).

## Админ

### `/admin/login`
Простая форма. `POST /api/admin/login`. Успех → `/admin/players`.

### `/admin/players` — лайв-список игроков
**Назначение:** видеть всех (активных и завершённых) игроков, скрывать с дашборда.
**Логика:**
- На монт: `GET /api/admin/sessions` + подключение к Socket.IO с `auth.role='admin'`.
- Слушает `players:new`, `players:update`, `players:finished`, `players:visibility` — обновляет локальный стейт.
- Таблица колонок: Имя, Старт, Длительность, Прогресс (X/Y), Очки, Статус, Действия.
- Действие «Скрыть с дашборда»: `PATCH /api/admin/sessions/:id/visibility`.
- Адаптив: на телефоне — карточки вместо таблицы.

### `/admin/questions` — конструктор
**Назначение:** список вопросов + редактор каждого типа.
**Логика:**
- `GET /api/admin/questions` → список с drag-and-drop сортировкой (по `orderIndex`).
- Тогглы `active`, отображение типа и базовой ставки.
- Кнопка «Создать вопрос» → модал/страница с выбором типа → форма по типу.
- Под каждый тип — свой редактор:
  - `grid3x3`: 9 слотов аплоада, под каждым чекбокс «правильный».
  - `tiles`: один аплоадер фото, ползунки `cols`/`rows` (2–6), кликабельная сетка поверх изображения.
  - `slider`: два аплоадера (фон + объект), клик по фону задаёт `target.x/y`, поле `tolerance`, переключатель `axis`.
  - `audio`: аплоадер mp3/ogg/wav (плеер с предпрослушкой), поле `expected`, переключатель `mode` и `maxDistance`.
  - `imageCode`: аплоадер картинки, поле `expected`, `maxDistance`.
- Каждый аплоад — `POST /api/admin/uploads`, ответ кладётся в payload-черновик.
- Сабмит формы: `POST /api/admin/questions` или `PATCH /api/admin/questions/:id`.
- Тогглы и порядок: `PATCH /api/admin/questions/:id/active`, `PUT /api/admin/questions/reorder`.
- Сверху — индикатор «Суммарный бюджет: 4:30» (сумма `timeLimitMs` активных).

### `/admin/*` — общая логика
- Все ответы 401 → редирект на `/admin/login`.
- Кнопка «Выйти» в шапке → `POST /api/admin/logout` → `/admin/login`.

## Публичный

### `/dashboard` — fullscreen топ-10
**Назначение:** проектор/телевизор на станции. Без авторизации.
**Логика:**
- На монт: `GET /api/dashboard/top` + Socket.IO c `auth.role='dashboard'`.
- Слушает `top:update`, плавно анимирует смены позиций (например, framer-motion).
- На карточке: ранг, Фамилия + инициал, очки.
- Фон — фирменный знак КампусФеста, крупная типографика Onest.
- Скрыть курсор, авто-fullscreen при F-клавише (или просто крупный layout без шапок).

## Бренд-ассеты на фронте
Положить `brand/` в `web/public/brand/` и использовать SVG-логотипы напрямую. Шрифт Onest подключить через `@fontsource/onest` или Google Fonts.

## Состояние и кеш
- Глобально — Zustand-сторы: `playerStore` (текущий вопрос, прогресс), `adminStore` (сессии, вопросы), `dashboardStore` (топ).
- Никакого SWR/React Query — экранов мало, ручной fetch + обновление по socket-событиям достаточно.
